# 楼兰 · 丝路物语 —— 核心概念与机制探索

> 版本 0.1 · 头脑风暴阶段
> 定位：开罗游戏式的轻松经营感 × 大航海时代式的贸易探索 × 活的角色人生模拟
> 主题：丝绸之路，异域风情，物品、故事与人的命运

---

## 一、一句话概念

**你经营一支往返于丝绸之路上的商队，但真正的"货物"不只是丝绸和香料——还有故事、技艺、信仰和人的命运。**

玩家不是在管理数字，而是在见证一条路如何改变途经它的每一个人。

---

## 二、核心循环（Core Loop）

```
组建商队 → 选择路线 → 途中事件 → 抵达城市
   ↑                                    ↓
 角色成长 ← 声望/财富/收藏 ← 交易/交流/收集
```

开罗式的"数值滚雪球 + 收集图鉴 + 小人动画"作为底盘，
大航海式的"港口(绿洲城市)间价差贸易 + 未知区域探索"作为骨架。

---

## 三、机制清单（按新颖度和联动性排序）

### ★★★ 1. 角色人生轨迹系统（本作灵魂）

每个角色（商队成员 + 城市NPC）不是固定职业的工具人，而是有
**性格、爱好、信仰、牵挂** 四个维度的"活人"。

- **人生转折点**：环境变化或事件会触发角色的转折——
  - 驼夫在沙暴中死里逃生 → 皈依佛门，成为僧侣，离开商队（但日后在寺庙为你提供庇护）
  - 商人的女儿在龟兹听到琵琶乐 → 放弃继承家业，成为乐师，追随乐队西行
  - 战乱让铁匠失去铺子 → 加入你的商队，途中爱上修驼具，转职为驼具匠
- **玩家可影响、不可控制**：你可以劝说、资助、介绍人脉来"推一把"，
  但角色有自己的意志。有时候留不住人，反而是新故事的开始。
- **命运回响**：离开的角色不会消失——他们在世界里继续生活，
  多年后你会在另一座城市遇到他们，人生轨迹完全不同。

### ★★★ 2. 故事作为可交易的"货物"（传话游戏机制）

丝路上流通的不只是货物，还有**故事、传说、消息**。

- 在茶馆、驿站、篝火旁**收集故事**（一段传说、一条商情、一个秘闻）
- 把故事带到另一座城讲述 → 换取金钱、声望或情报
- **故事会变异**：每经一次转述，故事会走样（长安的"白蛇"传到波斯变成"白龙"）——
  变异后的故事可能更值钱，也可能引发误会事件
- **消息有保鲜期**："于阗玉价暴涨"的情报三个月后就一文不值
- 图鉴系统收录你收集过的所有故事版本，集齐一个故事的全部变体有特殊奖励

### ★★★ 3. 文化融合合成系统

货物 × 货物、货物 × 技艺、技艺 × 人，都可以**融合出新东西**。

- 中原丝绸 + 波斯染料 = 晕染锦（新商品）
- 龟兹乐 + 中原诗 = 新曲目（乐师角色解锁演出）
- 造纸术传到撒马尔罕 = 该城市产业升级，长期改变物价
- 配方不是菜单里查的，而是**通过角色互动发现的**——
  一个波斯染匠和一个蜀锦织工在你的商队里同行三个月，某天篝火事件触发灵感

### ★★ 4. 会呼吸的路线与城市（动态地图）

- 你常走的路线会**繁荣**：驿站出现、村落成镇、盗匪减少
- 被冷落的路线会**荒废**：绿洲缩小、城市衰败
- 核心意象：**楼兰的兴衰**。水源（孔雀河改道、罗布泊干涸）是隐藏的大时钟，
  玩家的选择能延缓或加速一座城的命运——但无法永远阻止
- 大航海式的"未知区域"：地图边缘有雾，雇向导、学星象、追商队传闻来开拓新路线

### ★★ 5. 信息与语言经济

- **语言是技能树**：粟特语、于阗语、波斯语……会的语言决定你能做的生意、
  能听懂的故事、能招募的人
- 翻译/通译是稀缺角色，抢手且有自己的立场（可能偷偷抽成、传假话）
- 不懂语言时的交易会有"鸡同鸭讲"小剧场（开罗式幽默感）

### ★★ 6. 商队即卡组（构筑式编队）

商队 = 成员 + 骆驼 + 货物 + 装备的组合，类似轻量卡组构筑：

- 途中事件用商队构成来解：遇沙暴 → 有老向导则化险为夷；遇盗匪 → 镖师、
  名声、或"讲个故事贿赂头目"（收集的故事此处也能当资源用！）
- 成员之间有**羁绊/矛盾**：僧侣和酒商同行会互相看不顺眼，触发事件链

### ★ 7. 季节·星象·风物历

- 沙暴季、雪封山口、河水汛期决定路线开闭（大航海的季风机制陆地化）
- 夜行靠星象（学会星图技能后开放夜间赶路，避开白天酷热）
- 各城市有节庆日历：赶上于阗的玉市大集、撒马尔罕的新年，物价和事件都特殊

### ★ 8. 双时间线：考古回响（大胆的可选机制）

- 隐藏的第二层玩法：**千年后的考古学家视角**
- 你在商队时间线埋下/遗落/赠出的物品，会成为考古时间线里出土的文物
- 你商队里角色的人生故事，成为考古学家破译的文书残片
- "楼兰美女"、佉卢文简牍这些真实考古元素都能对应上
- 情感锚点：游戏想说的正是——路会被沙埋，故事会留下来

## 四、机制如何互相咬合（联动示例）

> 一场沙暴（季节系统）逼你改走南道 → 途中救下的乐师加入商队（角色系统）
> → 她与队里的龟兹鼓手合作出新曲（文化融合）→ 新曲在长安演出爆红（故事传播）
> → 长安贵族指名要"演出中提到的波斯银器"（需求被故事创造，动态经济）
> → 你为此开辟新路线（探索）→ 新路线让某座小镇繁荣起来（动态地图）
> → 乐师在那座镇上定居开了乐坊，离开商队（人生转折）
> → 多年后，乐坊成为你商队的据点，她的学生加入你的商队（命运回响）

**设计原则：每个系统的输出都是另一个系统的输入。**

---

## 五、风格基调

- 画面：开罗式像素小人 + 敦煌壁画色板（土黄、石青、朱砂、金）
- 情绪：80% 温暖幽默的日常经营，20% 命运与时间的怅然（楼兰主题自带）
- 文本量：小而美的碎片化叙事，靠角色小传和故事图鉴堆积世界感

## 六、待讨论的问题

1. **平台与形态**：手机竖屏放置向？还是 PC/Switch 横屏沉浸向？影响操作密度设计
2. **一局的长度**：开罗式的"若干年后结算评分"？还是无尽沙盒 + 世代传承？
3. **角色数量规模**：深度模拟 30 个角色，还是浅模拟 300 个？（建议前者）
4. **双时间线机制**是核心卖点还是彩蛋级内容？
5. 战斗要不要做？（倾向：不做传统战斗，冲突全部用事件+商队构成解）
