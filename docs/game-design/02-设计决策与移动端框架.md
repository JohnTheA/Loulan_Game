# 02 · 设计决策与移动端框架

> 版本 0.1 · 已确认的方向性决策，以及由此推导的框架设计

---

## 一、已确认的决策（2026-07）

| # | 问题 | 决策 |
|---|------|------|
| 1 | 平台形态 | **手机优先，竖屏** |
| 2 | 一局长度 | **开罗式：若干年后结算评分**（结算后可继续自由玩） |
| 3 | 角色规模 | **深度模拟 30 个角色** |
| 4 | 战斗 | **不做传统战斗**，一切冲突用事件 + 商队构成解 |

待定：双时间线（考古回响）做核心卖点还是彩蛋级内容 → 暂按**彩蛋级**规划，
结算画面用"千年后的出土文物"形式呈现玩家一局的足迹，成本低、点题准。

---

## 二、一局的结构

- **游戏内时长：15 年**（第 15 年年末结算，之后进入自由模式）
- 时间颗粒：1 年 = 4 季，1 季 = 1 个"行程段"（一次城际旅途或一段驻留）
- 节奏参考：一个行程段 = 一个 3~5 分钟的手机碎片 session
- 每年年末有"年话"小结算：这一年商队的故事回顾（自动生成的角色小事记）

### 结算评分维度（五轴，对应五个系统）

| 维度 | 来源系统 |
|------|----------|
| 财富 | 贸易 |
| 声望 | 各文化圈声望之和与均衡度 |
| 见闻 | 图鉴完成度（故事/商品/配方/星图） |
| 缘分 | 见证或促成的角色人生转折数、命运回响达成数 |
| 足迹 | 探索开拓的路线、影响过兴衰的城市 |

结算画面（彩蛋点题）：以"考古出土"的形式回放——你送出的礼物成为文物，
角色的人生成为文书残片，评分越高出土的东西越多。

## 三、移动端竖屏核心界面

```
┌─────────────┐
│  上：世界/路线图 │  ← 捏合缩放，看商队位置与天气
├─────────────┤
│  中：主舞台     │  ← 像素小人层：旅途行进 / 城市街景
│  （事件卡片弹出区）│
├─────────────┤
│  下：操作面板    │  ← 单手拇指区：商队/货物/角色/图鉴 四个 tab
└─────────────┘
```

- **旅途半自动推进**：商队在路上自己走（可 2 倍速），玩家只在事件卡片弹出时做选择——
  开罗式"看着小人忙碌"的乐趣 + 低操作密度
- **城市驻留**是操作密集段：交易、招募、听故事、逛集市，全部大按钮卡片式 UI
- 无网单机、非放置挂机；离开游戏时时间暂停（半放置的"旅途加速"满足挂机感）

## 四、30 个角色的预算分配

| 池 | 数量 | 模拟深度 |
|----|------|----------|
| 商队成员上限 | 12 | 全维度实时模拟（性格/心情/羁绊/转折） |
| 世界核心 NPC | 18 | 全维度，按季更新（分布在各城市：商人/乐师/僧侣/向导/译者…） |
| 离场角色池 | 不限 | 简化模拟（每年 1 次状态机更新，等待"重逢钩子"触发） |

核心 NPC 可被招募进商队（占用商队位），商队成员也可能转折离队进入离场池——
**30 个"活人"是流动的，不是固定名单**。

## 五、系统优先级（开发排序）

1. **P0 骨架**：时间推进 + 3 城地图 + 基础贸易（价差、载重）
2. **P0 灵魂**：角色人生轨迹系统（见 03 文档）
3. **P1**：故事收集与传播（含变异）、事件卡片库
4. **P1**：文化融合合成（配方靠角色互动发现）
5. **P2**：动态地图（路线兴衰、楼兰水源时钟）、语言技能树
6. **P2**：季节/星象/节庆历
7. **P3**：结算之"考古出土"演出、图鉴完善

原则：P0 两项做完就应该"好玩得起来"——纸面原型阶段只验证 P0。
