# 楼兰 · 丝路物语 —— P0 可玩原型

手机竖屏 HTML5 原型，纯前端零依赖，用于验证设计文档 03 的最小循环：
**贸易 + 故事 + 角色人生转折 + 命运回响**。

## 怎么玩

```bash
cd prototype
python3 -m http.server 8000
# 手机或浏览器打开 http://localhost:8000
```

或直接双击 `index.html` 也能玩（无任何构建步骤）。

## 已实现（对照 03 文档 P0 清单）

- ✅ 3 座城（敦煌—楼兰—于阗）+ 5 种货 + 价差贸易 + 15 年时钟（60 季）
- ✅ 7 个角色，完整四维数据结构（性格/爱好/信仰/牵挂 + 传记）
- ✅ 8 条人生转折规则（劫后皈依 / 乐音入梦 / 归乡之心 / 玉市萧条入队 /
  织音成锦 / 老骥归山 / 崖边拜师 / 夜观星河），规则表 + 掷骰 + 年度戏剧配额
- ✅ 人生卡片三选一流程（玩家可影响、不可控制）
- ✅ 完整命运回响链：离队 → 每年离场简化模拟 → 重逢事件（5 种）
- ✅ 故事收集与异地讲述（远途溢价）、故事可用于贿赂盗匪
- ✅ 文化融合配方（晕染锦）、楼兰衰落时钟（第 8 年起）、年话回顾
- ✅ 结算五轴评分 + "千年后考古出土"彩蛋

## 自动化冒烟测试

Playwright 驱动随机策略自动玩完整局（`?autotest=1` 下所有弹窗自动选择），
验证 15 年全流程无 JS 错误、可正常结算。测试脚本在开发会话的 scratchpad 中，
后续可移入 `prototype/test/`。

## 文件结构

- `index.html` — 竖屏三段式骨架（地图 / 主舞台 / 操作面板）
- `css/style.css` — 敦煌色板（土黄·石青·朱砂·沙白）
- `js/data.js` — 内容数据：城市、货物、角色、故事、事件卡
- `js/engine.js` — 引擎：时间循环、贸易、人生转折、离场模拟、结算
- `js/ui.js` — 渲染、Promise 化弹窗、旅途动画
